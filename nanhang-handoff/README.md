### 已确定的五个关键决定

1. 首版先做高三目标探索，高考后辅助单独设置开放门槛。
2. 平时成绩不直接换省位次；只凭高考总分给同分范围，不生成伪精确个人排名。
3. 专业组投档/录取、具体专业录取分开；没有专业数据就不判断专业录取门槛。
4. 前端React + TypeScript + Vite，匹配为纯规则模块；Python/SQLite离线数据工程，Node在线AI服务，公共数据版本化发布。
5. 本校先导入本人最小摘要；门禁与学生身份分开，云端成绩接入留到身份和部署边界完成之后。

## 2. 实际核查带来的三项修正

**质量慧析不能只看main。** 当前Pages工作流从不同固定提交组合版本；南溟应以accuracy-v1.2对应提交6f70eab4e6e9ecadc00149b1387103b45b5d8e2b的准确性改进作为学校适配基线。main中仍能看到旧的总分重建和重复行处理逻辑，不能倒退复用。

**官方在线入口的历史核查。** 当时读取的物理、历史入口是逐页图片浏览器，页面声明分别248页和160页，含多个招生类别，未发现结构化招生表API。用户随后提供Excel并指定为主输入，当前按工作表与单元格处理；图片/OCR仅用于必要的官方补证。

**北辰门禁不证明学生身份。** 北辰会话提供谈心访问和额度状态，没有绑定学生ID。该机制不能直接授予本人或他人成绩查询权限。南溟必须按单人协议与明确权限设计。
