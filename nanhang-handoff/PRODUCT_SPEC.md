## 1. 产品目标

服务四川普通类高三学生，帮助其形成“专业方向—不同层次的培养路径—学业目标—近期行动”的连接。成功不是输出更多院校，而是学生能解释自己的候选方向、知道依据与局限，并有下一步行动。

首版是目标探索工具。参加2027年高考是当前使用场景的默认年份建议，学生必须能修改；该建议不表示已经有2027年招生计划。2025/2026数据按实际取得情况逐步接入，年度事实严格分开。

## 2. 已决定的产品边界

| 决策 | 首版安排 | 后续扩展条件 |
|---|---|---|
| 产品阶段 | exploration：高三目标探索 | application_support需对应年度数据与资格规则另行验收 |
| 地区与类别 | 四川普通类，物理/历史分别处理 | 不提前设计全国规则引擎 |
| 招生范围 | 普通本科批B段、普通高考高职批的已核实一般招生样本 | 逐范围增加；特殊类型不得混入普通列表 |
| 培养路径 | 普通本科、职业本科、高职均可有示例 | 办学层次、证书与联合培养项目分别记录 |
| 学业定位 | 校内位置与目标情景；有官方高考资料时进行同年定位 | 模考到高考的预测校准默认关闭 |
| 职业探索 | 无AI快速探索＋可选AI谈心 | 细化专业资料与任务体验 |
| 本校模式 | 本人单人摘要导入，先不建设云端成绩库 | 身份、绑定与访问控制完成后再开启自动连接 |
| 结果 | 候选方向、历史参考、航线图与行动 | 不生成正式志愿顺序，不代填 |
| 维护 | 版本化数据发布工具与最小异常清单 | 有真实频次后再建设维护界面 |

首版样本覆盖矩阵建议为2个类别×3种培养层次，每格至少有经核实的示例。若某格资料不足，显示“当前暂无核实样本”，不以另一格替代，也不宣称完成了该格覆盖。数量目标不是保证数据存在的承诺。

## 3. 两个入口与两种阶段

入口与阶段是两个独立字段：entry=general/school_import；mode=exploration/application_support。学校入口不代表数据更准确，也不能自动解锁志愿辅助。

### 3.1 通用入口

无需账户即可浏览专业内容、手工填写必要信息、计算公共数据情景。AI谈心若产生费用，可通过独立访问凭证控制；失去AI额度不影响公共事实查看。

必要信息：目标高考年、省份、首选科目；需要资格筛选时补齐两个再选科目。成绩可暂不填。费用与地域偏好可跳过。

### 3.2 本校摘要入口

第一步由学校工作人员在自己的质量慧析环境中导出单个学生最小摘要，再由学生本人导入南溟。不得把全班或全年级数据交给学生浏览器后再隐藏他人行。

导入摘要本身不构成身份认证：无签名或无服务器核验的导入文件，显示“本地导入、未核验身份来源”，仅用于本人探索，不能授予服务器读取成绩权限。文件被修改不会造成额外权限或官方可信标记。

### 3.3 高考后阶段

界面开关默认关闭。须针对明确的年份、类别、批次、招生类型发布可用性声明；未覆盖范围不可放行。即使开放，也只给依据明确的参考，不输出录取承诺。所需后续任务见GATE-APP。

## 4. 主流程与页面状态

支持前后返回修改，不强制先完成长对话。

| 页面 | 用户动作 | 系统输出与必有状态 |
|---|---|---|
| 起点 | 选年份与选科，选择浏览、输入成绩或导入摘要 | 数据覆盖说明；未填成绩也能继续 |
| 学业位置 | 指定成绩类型、考试信息或目标分 | 分数口径；可定位/仅校内/仅情景/资料不足 |
| 专业探索 | 选具体学习任务与偏好，或开始谈心 | 可修正方向、证据与未知，不输出伪测评分数 |
| 方向对比 | 了解课程、任务、学习成本与相近专业 | 收藏、排除、继续了解，不把一个专业等同单一职业 |
| 路径参考 | 筛地域、费用、层次等 | 符合已检查条件/待核对/不符合/资料不足分开 |
| 航线图 | 选阶段目标与行动 | 方向、学业依据、参考院校、1—2项近期行动与复盘点 |

结果卡可展开细节，默认首先显示学生关心的内容；年份、参考类型和关键未知不能藏到展开区。

应用状态至少包括：empty、editing、calculating、ready、partial、failed。开始新探索产生新的run_id，旧AI流和旧计算结果不得覆盖新流程。

## 5. 学业输入与文案

成绩类型枚举固定为gaokao、mock、school_exam、target_scenario。

- gaokao：必须有成绩年度和明确计分口径；只有总分时按同分范围处理。
- mock：必须知道考试身份与参照范围，默认只显示模考结果，不转换官方省位次。
- school_exam：展示本人可比考试变化、校内位置、模拟线差；来源不明的线不参与达线结论。
- target_scenario：明确写“假设在2026年取得该分数的历史情景”等，不显示“预测高考成绩”。

不完整输入无需全部阻断。例如选科未填完整可以继续探索，但资格状态保持待核对；缺少成绩可以看专业，但不出现学业匹配标签。

默认不把空值替换成零、不用不完整科目重建总分、不把校排名除以人数当作省百分位。

## 6. 参考卡片与标签

每张卡必须有：学校与专业/大类、培养层次、年度与来源、专业组适用信息、学业依据类型、资格检查范围、数据缺口、下一步动作。

三组标签独立显示：

1. 条件：符合已检查条件 / 待核对 / 不符合；不显示无范围的“可报”。
2. 学业：历史位置较有余量 / 同分或边界重叠 / 需要更好位置 / 暂无比较依据。这里只描述历史位置关系。
3. 兴趣：学生已确认方向 / 待进一步了解。不能用兴趣强弱改写学业关系。

“努力目标”由学生收藏或设定，不等于算法认定能够达到。“当前参考”和“拓展了解”也不是录取概率分档。

专业组有历史数据、专业没有时，明确显示“两层证据不一致”；不把组线填到专业录取线字段。

## 7. 职业探索规格与实施边界

首版方向通常3—5个，材料少可以更少。结构化画像应含：方向ID、学生确认状态、证据消息ID、兴趣描述、愿意投入的学习任务、现实约束、矛盾点、待了解问题、下一步体验任务。

推荐理由必须能定位学生实际表达；“喜欢游戏”“愿意帮助别人”等单一描述不得直接推导专业。学生可否认AI判断，否认后对应判断退出有效画像，但历史修正记录可保留在本人本地。

专业事实来自已核实的专业介绍和学校培养资料。AI可以帮助理解，但不得编造课程、就业率、薪资、读研门槛、执业资格或录取条件。

TASK-06最小内容已在packages/exploration实现，包含问题、学生可否认画像、体验卡和有来源专业卡，详见工程docs/TASK06_CONTENT_SPEC.md；教师学生试用尚未开展。后续内容扩充不得改动成绩校准边界、证据规则或报考资格逻辑。涉及这些边界的变更按ADR流程提出。

## 8. 航线图

固定包含：

- 我目前确认的方向及理由。
- 仍不确定的内容与现实条件。
- 不同培养层次的参考路径，含证据年份与粒度。
- 当前位置与目标情景；没有有效定位时直说尚不能比较。
- 接下来两周1—2项行动，学生可修改。
- 下一次复盘时间或触发条件，如完成体验任务、下一次可比考试。

允许浏览器打印与下载本人JSON摘要；PDF生成可以用打印样式，不要求首版引入复杂导出服务。共享设备默认不持久保存私有信息；保存到本机必须主动选择，并提供一键清除。

“提高20分”仅改变target_scenario的分数，其他参考年度、类别、数据版本保持不变。不能把月考加20分当作高考加20分。

## 9. 非功能目标（工程预算，非已测事实）

- 在普通手机屏宽下无横向溢出；来源和限制可读，键盘不遮住提交动作。
- 公共浏览与匹配不依赖AI；明确的空结果优于无限加载。
- 静态首屏JS压缩体积建议控制在300KB级，数据按年/类别分片加载；具体数字可经测量调整并记录。
- 本地匹配在约定的样本规模下目标小于300ms；验收必须写明设备与数据规模。
- AI按系统规格设置超时与中断；不向学生展示内部推理过程。
- 无障碍：表单标签、键盘操作、焦点恢复、减少动态效果支持。
