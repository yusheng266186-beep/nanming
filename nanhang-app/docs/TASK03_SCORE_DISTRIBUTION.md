## 抽取方法

表图是三列版式（分数 / 人数 / 累计）逐块排列。抽取按项目既有的词坐标对齐约定：

1. Windows OCR 取词级文本与包围盒。每页按 1x、2x、3x 三个尺度各读一次（超过 OCR 尺寸上限的尺度跳过），读数交叉核对。
2. 按 x 中心把数字词聚成三列；分数列取**最左的**「按 1 递减游程」列——低位段人数也可能连续，只靠连续性会误判。
3. 同一格内被 OCR 切碎的片段按行合并；合并只做「补回丢失字符」，跨越宽空隙的片段不拼接。
4. 人数列与累计列按**列归属**配对，不按出现顺序；行配对容差按行距缩放，避免漏读格抢用邻行数值。
5. 每行保留分数、人数、累计、页码、图片名与该行三个数值的像素坐标。

**完成与修复分开记录**，每一处都写出依据：

| 类别 | 含义 | 本次数量 |
|---|---|---:|
| 算术闭合 | `cumulative(s) = cumulative(s-1) + count(s)`，全部满足 | 7/7 张表 |
| 由累计差补回 | OCR 漏读的人数按与上一行之差补回 | 见各表 `count_derived` |
| 丢字恢复 | 读数与算术确定值呈「丢字」关系时按算术恢复，并记录原读数 | 见 `arithmetic_repairs` |
| 数列恢复 | 整页为连续递减数列时按行位置恢复被误读的分数 | 见 `scores_restored_from_run` |
| 读图确认 | 三个尺度都读不出、按官方原图直接读取确认 | 2 处（见下） |
| 待人工核对 | 算术无法唯一确定，保持原样并列出候选 | 0 |

两处读图确认（`verified_score_rows.py`，含定位说明）：

| 表 | 分数 | 人数 | 累计 | 原因 |
|---|---:|---:|---:|---|
| 2023 理科 | 694 | 18 | 109 | 该行人数格在 1x/2x/3x 均未被 OCR 读出 |
| 2025 历史类 | 655 | 13 | 105 | 同上 |

**官方表未列出的分数不是 0 人**：某分数无人达到时官方不印该行。全部记入 `unlisted_scores`，不插值、不补 0。

核心算术不变量（各表均成立）：

- `count(s) = cumulative(s) − cumulative(s')`，s' 为相邻的上一个公布分数。
- 全区求和闭合：`Σ count + 表顶之上人数 = 最低公布分数的累计`。表顶之上的人数是官方发布的真实性质（最高公布分不是全体最高分），不是缺口。
- `rank_best = cumulative − count + 1`，`rank_worst = cumulative`，与规格第 6 节一致。

## 入库

| 表 / 视图 | 内容 |
|---|---|
| `score_distribution` | 每表一行：年份、省份、科类、口径、分数范围、行数、最低分累计、表顶之上人数、来源页、快照运行、核验状态 |
| `score_distribution_row` | 每个公布分数一行：人数、累计、`rank_best`/`rank_worst`、`count_derived` 与算式、证据图片与图片 SHA-256、三个数值的像素坐标 |
| `v_score_distribution_row` | 上述两表连接后的查询视图 |

`verification_status = VERIFIED` 的依据：来源是考试院官方发布，逐行可回溯到登记的图片与 OCR 坐标，官方算术闭合，且抽取读数经多尺度交叉核对。

**计分口径**：官方图片表头未标注口径。按该表的发布用途记为 `gaokao_cultural`，同时以 `score_basis_status = NOT_STATED_ON_PUBLISHED_TABLE` 标明这是**用途推定而非原文声明**。

## 匹配中的用法

```powershell
py -3.12 pipelines/task03/query_admissions.py --track 物理 --score 600 --subjects 化学,生物 `
    --batch 本科批B段 --level 本科 --sort history_position --limit 20
py -3.12 pipelines/task03/query_admissions.py --track 物理 --score 600 --score-year 2025 --limit 20
```

行为（对齐规格第 6 节 `locateRank`）：

- 分数在公布范围内且该分数有行 → 输出位次区间，比较时取区间下界，并说明出处与核验状态。
- 分数在表内但无对应行（无人达到）→ `NO_OBSERVED_SCORE`，不做插值。
- 低于公布最低分 → `OUT_OF_DISTRIBUTION_COVERAGE`，不外推。
- 高于公布最高分 → `ABOVE_PUBLISHED_RANGE`，不制造精确位次。
- 考生自报位次优先：同时给 `--rank` 与 `--score` 时用 `--rank`。
- `--score-year` 选择年份；该年度的科类口径由 `DISTRIBUTION_TRACK_BY_YEAR` 决定（2024/2023 年物理工作表的历史列按理科表核对）。

## 边界

- 表内位次是**分段区间**，不是个人精确位次；同分考生无法进一步排序，不推算个人名次。
- 各表的最低公布分不同（2023 理科 100 分，其余 150/151 分），其下考生不在覆盖范围。
- 2024/2023 为文理分科口径，与物理类/历史类不是同一定义；库与发布包都用 `curriculum_system` 标明，查询层按年份显式映射，不做跨口径自动等同。
- 本表不用于构建录取概率，也不与历史录取线直接构成预测关系。
