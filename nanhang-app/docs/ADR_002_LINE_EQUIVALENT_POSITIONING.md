# ADR-002: 定位页引入「线差比例等位参考」与官方控制线登记数据

- 状态：已接受（2026-09-12，负责人批准实施）
- 关联：修订《DATA_AND_MATCHING_SPEC》§1/§7.1/§7.2 的部分结论与《SYSTEM_AND_INTERFACE_SPEC》§5.1 的「不导入公共省控制线表」；设计基线仍为 2026-09-09 / 1.0.0，规则包 nh-rules-1.0.0 不变
- 背景需求：负责人指出定位页没有「近几次考试成绩」的录入入口，无法回答「我离特控线/本科线多远、换算到高考大约什么位置」这一学生最关心的问题。

## 问题

原规范两条裁决挡住了这个功能：

1. 「平时成绩不换省位次、不做模考到高考的预测」（DATA_AND_MATCHING_SPEC §1/§7.1）；
2. 「不导入公共省控制线表」（SYSTEM_AND_INTERFACE_SPEC §5.1）。

而发布包当前只有一分一段表（2023–2026 共 7 张，VERIFIED），没有任何控制线数值。

## 决定

1. **录入**：定位页新增近五次考试录入（总分/位次/本次特控线/本次本科线，均可是选填）。
   数据建模为 `WebForm.exams: ExamRecord[]`，与增强模式回填共用同一结构；缺失一律 null 不按 0。
   位次仅作展示，不得当作省位次（契约校验 NON_GAOKAO_PROVINCE_RANK 的语义继续有效）。
2. **官方线**：以静态、带来源登记的方式引入 2026 年四川省特控线与本科批线
   （`apps/web/src/reference-lines.ts`；来源：四川省教育考试院 2026-06-25 发布页，URL 见文件内登记）。
   数值变更必须同步来源与日期。
3. **等位算法（线差比例法）**：距线比例 =（总分 − 本次线）÷ 本次线；等位分 = 官方同年同口径线 ×
   （1 + 距线比例），四舍五入取整后回查**同一年**的官方一分一段表得位次区间与百分位。
   特控线口径与本科线口径并列展示、不平均、不合并成单点。
4. **边界（不变量）**：
   - 等位结果只存在于定位页展示层，**不进入匹配输入**（match 仍只吃学生手填的目标情景分）；
   - 页面文案必须写明「估算参考，不是预测」及其假设（本次考试难度与高考同比例）；
   - 不生成单点结论：位次用分段表区间表达，口径间不一致时并列呈现；
   - 等位分允许学生**手动**点按钮设为情景分——情景分本身就是「假设在目标年取得该分」的用户输入，
     由学生主动选择，系统不得自动代填。

## 理由与被放弃的选项

- 纯线差法（绝对差）对满分口径不同的考试不稳健，被比例法取代（负责人裁定）。
- 百分位映射法需要考试人数与「校考人群≈全省人群」的强假设，规范 §7.2 已明确警惕，放弃。
- 继续不做任何转换则无法回应学生的真实问题，放弃。

## 影响与迁移

- 四份冻结 Schema 不变（学生下载的 form JSON 形状变化属于应用层导出，不是合同对象）。
- domain / match-input 不变；新增纯函数集中在 `apps/web/src/exam-position.ts` 并有单测护栏。
- 若未来要做真正的「模考→高考」统计校准，仍须满足 DATA_AND_MATCHING_SPEC §7.1 的全部证据要求，
  本 ADR 不构成对那条路径的豁免。
