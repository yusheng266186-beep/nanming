## 实现与取舍

- 首页保持画框稳定，潮汐与光感走 transform/opacity；桌面视差仅写 CSS 变量，触屏不触发指针视差或按下涟漪。系统减少动态效果和本次会话关闭立即生效。
- `.deck` 共用 480ms `--motion-settle`。`Disclosure` 初次打开挂载，之后保留正文使关闭和快速反向连续；inert/aria-hidden 同步开合。`overflow:clip` 裁切正文而不把 sticky 改为局部滚动。曾打开的内容留在 DOM（各页原有挑选上限仍生效），换章节/结果时按既有 React 生命周期处理。
- 卡堆的 sticky top 从实际卡片 computed style 获取，避免从外层容器读到缺失的自定义属性或无法解析的 calc；降低滞后幅度，关动效归零姿态。`motion.ts` 订阅系统媒体查询和 html 会话开关，并清理监听。
- 行装清单 ≥1000px 三项并列，窄屏顺序填写、压缩重复留白。三件备齐进度仍含选填目标分，必填缺项单独计数；不改变出发门禁。
- 定位只改布局与焦点样式，成绩行不再因焦点/悬停改变 padding。设置宽度上限540px，三档选择一行、选中说明共用一段；开关40px高、发布版本可折行。选项即时生效且仍只在当前会话内保存。
