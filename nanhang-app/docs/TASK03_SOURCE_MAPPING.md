## 招生计划字段映射

| 来源字段 | 样本字段 | 转换规则 | 缺失/冲突处理 |
|---|---|---|---|
| `科类` | `track` | `物理` → `PHYSICS`，`历史` → `HISTORY` | 未知值拒绝构建该行 |
| `批次` + 官方页标题 | `batch` / `stage` | `本科提前批(国家专项)` → `本科提前批次` + `stage=null`；`本科提前批A段` → `本科提前批次` + `A段` | 不从相邻批次猜测 |
| `计划类别` + 官方分区标题 | `admission_type` | 国家专项行写 `国家专项计划`；A 段公安页写 `公安、司法类` | 不把批次和招生类型合并成一个自由文本 |
| `院校代码` / `院校名称` | `institution_code` / `institution_name` | 代码按字符串保留前导零 | 名称仅用于对照，不单独作为稳定键 |
| `专业组代码` | `group_code` | 组表头值继承到同组后续专业行 | 组代码改变则立即停止继承；不跨院校/批次/科类继承 |
| `26专业组计划人数` | `group_plan_count` | 同组每个样本行保留相同组总数 | 若同组总数冲突则该组拒绝验证；节选行之和小于组总数只表示未完整覆盖 |
| `专业代码` / `专业名称` | `major_code` / `major_name` | 代码作字符串；名称保留源文 | OCR 将 `1B/1H` 误识为 `IB/IH` 时把自动提取状态记为 `CONFLICT`，保持 `PENDING_HUMAN`，不用 OCR 值覆盖工作簿文字层 |
| `26计划人数` | `plan_count` | 仅接受正整数 | 不从组总数均分或补齐 |
| `26学费` / `26学制` | `tuition` / `duration_years` | 数值原样保留 | 未知保留 `null` |
| `选科要求` | `subject_requirement_source` | 保留源字符串，本轮不扩展新的选科规则 | 不从专业名称猜选科 |

官方计划页采用多栏版式，Windows OCR 会串栏。因此结构字段从工作簿文字层取得，官方图片只是当前对照证据；未有人工签字前统一为 `PENDING_HUMAN`。

## 成绩分段字段映射

| 图片列 | 样本字段 | 转换 | 校验 |
|---|---|---|---|
| `分数` | `score` | 去掉显示后缀“分”，保留整数 | 按 OCR 词坐标的 y 值建行 |
| `人数` | `people_at_score` | 同一 y 行中栏整数 | 漏识保留 `null`；不用累计数差回填 |
| `累计` | `cumulative_count` | 同一 y 行右栏整数 | 仅做非递减结构检查，不等于人工核对 |

物理图样本中 679 分行的 `人数` 未被 OCR 识别，样本明确写入 `null` 与 `MISSING`。两张图均只是第 1 张节选，`excerpt_scope` 必须包含“非全表”。

## 历史录取字段映射

| 图片字段 | 样本字段 | 转换 | 未知与冲突 |
|---|---|---|---|
| 左侧专业组/专业行 | `group_name` / `offering_name` | 专业行保留两者；“组最低录取”汇总行的 `offering_name=null` | 不把组汇总行复制给专业 |
| `2025年` 列的 `分数/位次` | `score` / `rank` | 按行锚点和 2025 列 x 坐标取值 | 不把页面标题的 2026 套到历史列 |
| `…组最低录取分数及位次` | `metric_type=group_admission_min` | 只表示组录取最低 | 禁止改写为 `group_filing_min` 或 `major_admission_min` |
| 专业行的录取分数/位次 | `metric_type=major_admission_min` | 仅绑定该专业 | 禁止上提为组线 |
| 图中未逐行提供 | `batch` / `stage` / `admission_type` / `score_basis` | 统一 `null` | 字段名同时列入 `unknown_fields`，不根据当年常识猜测 |

## 冲突与发布边界

- 官方图片、OCR 与工作簿任一字段不一致，记为 `CONFLICT`，不以工作簿或“多数值”覆盖。
- OCR 漏识记为 `MISSING`，不算术重建；官方图中没有的口径字段保持 `null`。
- 同组继承只在同年、同科类、同批次/阶段、同院校代码内有效。
- `group_admission_min`、`group_filing_min` 和 `major_admission_min` 是三个独立口径；本轮没有取得 `group_filing_min`。
- 所有样本的 `human_review_performed=false`；模型阅图、OCR 内部检查和自动测试都不是人工验收。
