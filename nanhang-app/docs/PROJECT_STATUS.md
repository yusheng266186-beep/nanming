## 2026-09-14 / 服务开关升级：任意设备可用的网页（COS 页面 + 云端中转）

负责人要的是「随时能打开、任何设备都能用」的开关，并同意把密钥放在网页里。这一轮把它做成**云端中转**：静态网页放在 COS（手机、平板、任何电脑直接打开），网页只带「中转地址 + 控制口令」，真正的云端操作由新函数 `nanming-control` 执行，**腾讯云密钥只在函数环境变量里**。

- 网页：`https://nanming-100051087352-1459223409.cos.ap-chengdu.myqcloud.com/switch/b76b5b97.html`
