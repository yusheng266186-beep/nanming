## 实现与重建

`pipelines/quality-huixi/import_class4_codes.py` 读取文本型身份证单元格，拒绝数值单元格可能发生的精度损失；按规范化姓名与四班身份唯一匹配，遇同名歧义或越班匹配则拒绝写入。完整身份证仅在读取进程内使用；持久化覆盖表 `private/quality-code-overrides.json` 只含稳定本人ID与新码SHA-256，并登记源文件哈希。

`export_identity.py` 在每次导出时读取覆盖表，以新码摘要构造姓名＋码查询键，继续指向原本人分片。数据重建后必须重新执行此导出器，不能绕开覆盖表从旧CSV手工生成身份索引。旧的 `private/quality-huixi-codes.csv` 是历史发放/存储派生产物，其中已变更的48人旧码不再可用于新API映射。

在工程目录执行（读取工作簿需有openpyxl的Python，本次使用已配置的工作区Python运行时）：

```powershell
python pipelines/quality-huixi/import_class4_codes.py --workbook <负责人指定的身份工作簿> --apply
py -3.12 pipelines/quality-huixi/export_identity.py
node scripts/build_function.mjs
python pipelines/quality-huixi/verify_class4_codes.py --workbook <同一身份工作簿>
```

不传 `--apply` 只校验。导入前自动备份原覆盖表与身份索引到 `private/backups/`。覆盖表与身份索引均不进Git和源码包；云函数部署包仅附带身份查询摘要索引。需要回退时从对应私有备份恢复覆盖表并重新导出、打包，不能仅恢复网页。
